# 五校逐鹿 · 985 大学城动态淘汰赛

一款用 PHP + HTML + SQLite 构建的单机网页策略小游戏。灵感来自《瘟疫公司》的进化树与《反叛公司》的区域控制，但把病毒换成了**学术交流**、把军队换成了**食堂优惠券**、把战争换成了**谁才是双一流**。

> 纯属校园梗娱乐，不构成对任何高校的真实评价。所有校名、绰号与事件均为虚构调侃。

## 快速开始

要求：PHP 8.1+，启用 `pdo_sqlite`、`mbstring` 扩展。

```bash
cd /path/to/schools
php -S 127.0.0.1:8099 router.php
```

浏览器打开 `http://127.0.0.1:8099/`。

数据库会自动创建在 `storage/game.sqlite`。想重置全部存档，删除该文件即可：

```bash
rm -f storage/game.sqlite storage/game.sqlite-shm storage/game.sqlite-wal
```

## 核心玩法

- **五校逐鹿**：你控制一所高校，与四所 AI 高校争夺大学城 24 个区块。
- **学术渗透**：从相邻区块投放学科资源，渗透度达到 100% 即可接管。公共区域会打通更多扩张路线。
- **学科评估战**：与相邻高校硬碰硬，比拼师资、生源、经费与城防。胜则打瘫对方区块，败则自己掉支持率。
- **舆论战**：无视距离，直接削减对方校长支持率。支持率归零，学校提前出局。
- **校策树**：红专 / 白专 / 黑线三条路线，每线四个节点，不可全点。终极节点解锁杀招。
- **内部稳定**：学生怨气每周增长，超过阈值会爆发校内游行。食堂半价、取消早操能救急。
- **随机事件**：教育部突击检查、疫情封控、分数线波动、食堂刺客、樱花季游客潮……
- **三种终局**：控制 60% 区块吞并胜利；让所有对手支持率归零；第 60 周科研经费最高者胜。

每回合消耗**行政点**，行动消耗**科研经费**。结束本周后，AI 会行动、随机事件会结算，然后进入下一周。所有操作即时写入 SQLite，刷新页面即可继续。

## 自定义高校

开始页的五校名单全部可替换：

1. 点击任意一行右侧的 **＋**，打开“自建高校”申请表。
2. 可设置：正式校名、民间绰号、地图简称、校徽主色、王牌院系、校训、特长、短板。
3. 每所学校必须选择一项特长与一项短板。特长包括基建狂魔、嘴炮无敌、白衣天使、下饺子、巨无霸校区、少年班、顶流景区等。
4. 新建后会自动填入当前顺位，也可以继续创建更多自定义高校。
5. 参战五校不能重名。自定义高校会保存在浏览器 `localStorage` 中，下次打开仍可选择。

预设高校包括：清华大学（五道口职院）、北京大学（中关村文理学院）、复旦大学（五角场文秘职院）、上海交通大学（东川路男子职院）、浙江大学（三墩镇人民公园）、中国科学技术大学（南七技校）、武汉大学（珞珈山导游基地）。每局从中任选五所。

## 项目结构

```
.
├── index.php          # 页面入口（开始页 + 游戏页）
├── router.php         # PHP 内置服务器路由（保护 storage/lib）
├── api.php            # JSON API
├── config.php         # 学校预设、特长短板、校策树、数值配置
├── lib/
│   ├── db.php         # SQLite 连接与建表
│   └── game.php       # 游戏引擎：地图、行动、AI、事件、结算
├── assets/
│   ├── style.css      # 纸张 / 红头文件 / 地图视觉
│   └── app.js         # 开始页、地图交互、侧栏、弹窗、周报
└── storage/           # SQLite 数据（首次访问自动创建）
```

## 技术说明

- 前端无构建步骤、无第三方运行时依赖，直接由 PHP 输出。
- 地图为内联 SVG，区块颜色、渗透进度、城防、瘫痪状态都随服务端状态重绘。
- 服务端是唯一权威状态源；每次行动在一个 SQLite 事务中完成校验、结算与落库。
- 首次打开带 `?game=` 的页面时，服务端会把当前对局状态内联到 HTML，避免白屏等待。
- 开始页阵容保存于 `localStorage`，对局本身保存于 SQLite。

## 小提示

- 先拿公共区域，扩张路线会舒服很多。
- 城防会抵消渗透进度。打不动就先用学科评估战把目标打瘫。
- 支持率比经费更容易输光。食堂半价不是摆设。
- 红专适合速攻，白专适合长线，黑线适合斩首。不要三条线平均点。
