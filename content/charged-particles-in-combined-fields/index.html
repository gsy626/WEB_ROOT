复合场（磁场与电场）中带电粒子的运动

设空间中存在\bvec{B} = B_0 \hat{k} 和 \bvec{ F }

带正电粒子，初速度为 \bvec{ v_0 }, 电荷量为q

\bvec{ F } 大小为F_0

\bvec{ F } =F_x \hat{ i } + F_y \hat{ j } +F_z \hat{ k }

\bvec{ v_0 }= v_{ 0x } \hat{ i } + v_{ 0y } \hat{ j} + v_{ 0z } \hat{ k}

由牛顿第二定律

\bvec{ v } \times \bvec{ B } =& ( v_{ x } \hat{ i } + v_{ y } \hat{ j} + v_{ z } \hat{ k} ) \times B_0 \hat{k} \\

=& B_0 ( v_{ x } \hat{ i } \times \hat{k} + v_{ y } \hat{ j} \times \hat{k} + v_{ z } \hat{ k} \times \hat{k} ) \\

=& B_0 ( - v_x \hat{ j } + v_y \hat{ i } ) \\ =& - v_x B_0 \hat{ j } + v_y B_0 \hat{ i }

\end{aligned}

\bvec{ v } \times \bvec{ B } = ( v_{ x } \hat{ i } + v_{ y } \hat{ j} + v_{ z } \hat{ k} ) \times B_0 \hat{k}

= B_0 ( v_{ x } \hat{ i } \times \hat{k} + v_{ y } \hat{ j} \times \hat{k} + v_{ z } \hat{ k} \times \hat{k} ) = B_0 ( - v_x \hat{ j } + v_y \hat{ i } ) - v_x B_0 \hat{ j } + v_y B_0 \hat{ i }
q v_y B_0 +F_x =m a_x (1) \\ - q v_x B_0 + F_y = m a_y (2) \\ F_z = m a_z (3) \end{cases} $ \frac {(1) } {(2) } $ 得 E2 $ \bvec{ u_0 } = ( v_{0x} - \frac { F_y } { q B_0 } ) \hat{i} + ( v_{0y} + \frac { F_x } { q B_0 } ) \hat{ j } + v_{0z} \hat{ k } $ 则 $ u_x^2+u_y^2=u_{0x}^2+u_{0y}^2 即 \mid \bvec{u_{xy}} \mid = \sqrt{u_{0x}^2+u_{0y}^2} $ ### 下面先只考虑$ x $ $ y $方向 ![80%](image\fig2.png)
u_{xy}
T = 2 \pi \frac{\mid \bvec{u_{xy}} \mid}{ \mid \frac{ d \bvec{u_{xy}} }{ d t } \mid } = 2 \pi \frac{ \mid \bvec{u_{xy}}\mid}{ \frac{ qB_0 }{ m } \mid \bvec{u_{xy}} \mid } = \frac{ 2 \pi m }{ qB_0 } \omega = \frac{2\pi }{T}
\begin{cases} & u_x = \sqrt{u_{0x}^2+u_{0y}^2} \cos{\left( \omega t + \varphi \right)} \\ & u_y = \sqrt{u_{0x}^2+u_{0y}^2} \sin{\left( \omega t + \varphi \right)} \end{cases}

其中

\begin{cases} & u_{x0} = \sqrt{u_{0x}^2+u_{0y}^2} \cos{\left( \varphi \right)} \\ & u_{y0} = \sqrt{u_{0x}^2+u_{0y}^2} \sin{\left( \varphi \right)} \end{cases} \begin{cases} & \sin{ \varphi }=\frac{ v_{0y} + \frac { F_x } { q B_0 } }{ \sqrt{( v_{0x} - \frac { F_y } { q B_0 } )^2+( v_{0y} + \frac { F_x } { q B_0 } )^2} } \\ & \cos{ \varphi }=\frac{ v_{0x} - \frac { F_y } { q B_0 } }{ \sqrt{( v_{0x} - \frac { F_y } { q B_0 } )^2+( v_{0y} + \frac { F_x } { q B_0 } )^2} } \end{cases}
\begin{cases} & v_{x} = \frac{F_y}{qB_0} + \sqrt{u_{0x}^2+u_{0y}^2} \cos{\left( \omega t + \varphi \right)} \\ & v_{y} = -\frac{F_x}{qB_0} + \sqrt{u_{0x}^2+u_{0y}^2} \sin{\left( \omega t + \varphi \right)} \end{cases}

积分

\begin{cases} & x = \frac{F_y}{qB_0} t + \frac{ \sqrt{u_{0x}^2+u_{0y}^2} }{ \omega } \sin{\left( \omega t + \varphi \right)} - \frac{ \sqrt{u_{0x}^2+u_{0y}^2} }{ \omega } \sin{\left( \varphi \right)} \\ & y = -\frac{F_x}{qB_0} t - \frac{ \sqrt{u_{0x}^2+u_{0y}^2} }{ \omega } \cos{\left( \omega t + \varphi \right)} + \frac{ \sqrt{u_{0x}^2+u_{0y}^2} }{ \omega } \cos{\left( \varphi \right)} \end{cases}

\begin{cases} & x = \frac{F_y}{qB_0} t + \frac{ m \sqrt{u_{0x}^2+u_{0y}^2} }{ qB_0 } \sin{\left( \omega t + \varphi \right)} - \frac{ m u_{0y} }{ qB_0 } \\ & y = -\frac{F_x}{qB_0} t - \frac{ m \sqrt{u_{0x}^2+u_{0y}^2} }{ qB_0 } \cos{\left( \omega t + \varphi \right)} + \frac{ m u_{0x} }{ qB_0 } \end{cases}
