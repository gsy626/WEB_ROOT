STYLE GUIDE

风格说明

每种风格一个 CSS 文件，放在 WEB_ROOT/style/，博文页面只引用 base.css + 自己的风格文件。

怎么选风格

转换脚本按正文内容自动判定：只要正文里出现 LaTeX 数学（行内 $…$ 或行间 $$…$$），就归入 数理风格；没有公式的叙事性文本归入 休闲随笔风格；以图像、海报或纯绘图代码为主体的作品归入 图鉴风格。

三种风格

数理风格 · math.css

冷色纸面 + 极淡方格底纹，衬线正文，编号公式卡与定理式提示框。

判断规则：正文出现行内或行间 LaTeX 数学公式。

休闲随笔风格 · casual.css

暖纸底色 + 手写感标题 + 首字下沉 + 便签提示框，适合叙事与散文。

判断规则：不含数学公式的叙事、小说、随笔。

图鉴风格 · gallery.css

深色展台 + 大图展墙 + 代码展板，可点击放大，适合作品集与生成艺术。

判断规则：以图像、海报或绘图代码为主体，原理性叙述较少。

公共变量

三套风格共用 style/base.css 里的设计变量（纸色、墨色、强调色、字体、版心宽度），风格文件只覆盖变量与少量组件样式，因此新增风格只需再写一个 CSS 文件。
